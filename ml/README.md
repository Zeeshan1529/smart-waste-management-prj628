# ML Workspace

This folder is intentionally reserved for the project’s prediction module.

## Planned target
Predict near-future waste collection demand / fill-level risk using historical observations.

## Suggested features
- bin/zone ID
- timestamp (hour/day/weekend/festival)
- historical fill level
- collection frequency
- local waste reports
- weather (optional future input)

## Evaluation
Keep a held-out test set and report MAE/RMSE for regression or precision/recall/F1 for classification.
